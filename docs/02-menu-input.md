# 2단계. 메뉴·공통 입력·예외 처리

## 1. 수행 목표

메뉴 선택·재입력·종료 흐름을 만들고, 잘못된 입력과 입력 중단을 처리한다.

## 2. 학습 목표

- 변수와 str, int, bool의 차이를 설명한다.
- if/elif/else로 메뉴를 구분한다.
- while로 메뉴와 입력을 반복한다.
- 함수의 매개변수와 반환값을 활용한다.
- try/except로 숫자 변환 실패와 입력 중단을 처리한다.

## 3. 개발 환경

- Windows PowerShell
- Python 3.12.10
- Git 2.56.0.windows.4
- 프로젝트: C:\Users\user\quiz-game
- 실행 파일: main.py
- 외부 라이브러리 사용 없음

## 4. 구현 내용

### 기본 메뉴

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료

1~4번은 현재 메뉴 연결을 확인하는 임시 안내이다.
실제 퀴즈 기능은 후속 단계에서 구현한다.

### 함수별 역할

| 함수 | 역할 |
|---|---|
| show_menu() | 메뉴 출력 |
| read_int(prompt, minimum, maximum) | 공통 숫자 입력·검증·반환 |
| main() | 메뉴 반복·선택·종료 |

### 공통 입력 처리

- strip()으로 앞뒤 공백 제거
- 빈 입력이면 안내 후 재입력
- int() 변환 실패 시 ValueError 처리
- 허용 범위 밖 숫자는 안내 후 재입력
- 정상 입력은 정수로 반환

### 안전 종료

- KeyboardInterrupt: 취소 안내 후 종료
- EOFError: 입력 종료 안내 후 종료
- 현재는 저장할 게임 데이터가 없다.
- 파일 저장 기능 구현 후 가능한 저장까지 연결해 재검증한다.

| 검증 항목 | 실제 결과 |
|---|---|
| 기본 메뉴 1~4번 | 기본 메뉴 버전에서 각 임시 안내 출력·메뉴 복귀 확인 |
| 5번 | 게임 종료 안내 후 PowerShell로 복귀 |
| 공백을 포함한 1 | 퀴즈 풀기 안내 출력 |

| 빈 입력 | 빈 입력 안내 후 재입력 |
| 0 | 1~5 범위 안내 후 재입력 |
| 9 | 1~5 범위 안내 후 재입력 |

## 8. Ctrl+C 검증

프로그램을 실행하고 선택 입력을 기다리는 동안 Ctrl+C를 눌렀다.

```text
선택:
입력이 취소되어 게임을 안전하게 종료합니다.
```

PowerShell 자체에서 Ctrl+C를 누른 경우와 구분하여,
게임 실행 중의 종료 안내를 확인했다.

## 9. EOF 검증

표준 라이브러리 subprocess를 사용해 빈 입력으로 실행하고
출력과 종료 코드를 확인했다.

```powershell
python -c "import subprocess,sys; r=subprocess.run([sys.executable,'-X','utf8','main.py'],input='',text=True,encoding='utf-8',capture_output=True); print(r.stdout,end=''); print(r.stderr,end=''); print('종료 코드:',r.returncode)"
```

실제 출력의 핵심 부분:

```text
선택:
입력이 종료되어 게임을 안전하게 종료합니다.
종료 코드: 0
```

## 10. 문제 해결

| 문제 | 확인·해결 |
|---|---|
| 기본 메뉴에서 1번이 한 차례 거부됨 | 코드 확인 후 숫자만 직접 입력해 정상 동작 확인. 최초 원인은 확정하지 않음 |
| PowerShell에서 Ctrl+C를 누름 | 게임을 실행하고 선택 입력 대기 중 다시 검증 |
| PowerShell의 < 입력 리디렉션 오류 | Python 코드 실행 전 발생한 쉘 문법 오류임을 구분 |
| cmd 경유 EOF 검증에서 입력 안내 한글 깨짐 | subprocess로 입출력을 UTF-8로 처리해 정상 표시·종료 코드 확인 |
| 사진 경로 조회가 False | 바탕 화면의 menu.png를 제출 폴더로 복사 후 True 확인 |

## 11. 학습 내용

- str: input()으로 받은 문자열
- int: 문자열을 변환한 메뉴 번호
- bool: running의 True 또는 False 상태
- if/elif/else: 조건에 따른 처리 구분
- while: 메뉴 또는 재입력 반복
- 매개변수: prompt, minimum, maximum
- 반환값: read_int()가 돌려주는 정상 정수
- try/except: 예상한 오류를 안내와 재입력·종료 흐름으로 처리
